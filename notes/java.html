Java 程式設計

從物件導向到繼承、多型，快速複習 Java 核心觀念。

重要概念

Class 與 Object

Class（類別）是物件的藍圖，定義資料與行為；Object（物件）是類別建立的實體。

繼承（Inheritance）

子類別透過 extends 重用父類別的可繼承成員，並能覆寫方法。

多型（Polymorphism）

父類別型別的參考變數可以指向子類別物件，覆寫後的方法會依實際物件型別執行。

程式範例

class Animal {
    void speak() {
        System.out.println("Animal");
    }
}
class Dog extends Animal {
    @Override
    void speak() {
        System.out.println("Woof");
    }
}
public class Main {
    public static void main(String[] args) {
        Animal a = new Dog();
        a.speak(); // Woof
    }
}

Animal a = new Dog() 展示父類別參考指向子類別物件，呼叫覆寫方法時輸出 Woof。

重點整理

  • Class 定義結構，Object 是實例。
  • extends 建立繼承關係。
  • @Override 標示覆寫父類別方法。
  • 多型讓相同介面呈現不同實作行為。
