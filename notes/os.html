作業系統 OS

認識 Process、Thread 與 Race Condition 等核心概念。

重要概念

Process（行程）

正在執行的程式實例，具有自己的虛擬位址空間與作業系統管理的資源。

Thread（執行緒）

行程內的執行單位。同一行程的執行緒通常共用位址空間，但有各自的堆疊與執行狀態。

Race Condition（競爭條件）

當結果取決於多個執行緒或工作存取共享資料的時序，就可能發生競爭條件。

範例：共享計數器

// 假設兩個執行緒共用 count = 0
// Thread A: read count (0)
// Thread B: read count (0)
// Thread A: write count = 1
// Thread B: write count = 1
// 預期增加兩次，結果卻可能是 1

count++ 通常不是不可分割的原子操作。可以使用 mutex（互斥鎖）或適當的原子操作保護共享狀態。

重點整理

  • Process 是資源隔離與管理的重要單位。
  • Thread 是執行單位，行程內執行緒可共用資料。
  • 共享資料的讀寫時序可能造成競爭條件。
  • 同步機制能協助避免資料不一致。
