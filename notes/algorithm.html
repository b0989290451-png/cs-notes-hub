演算法 Algorithm

理解時間複雜度、排序與演算法設計的基礎概念。

重要概念

時間複雜度

Big O 描述輸入規模 n 增長時，演算法運算量的漸進上界。常見有 O(1)、O(log n)、O(n)、O(n log n)、O(n²)。

二分搜尋

在已排序的資料中，每次比較中間值，排除約一半搜尋範圍，時間複雜度 O(log n)。

合併排序

採用分治法，將陣列切成兩半、遞迴排序後合併，時間複雜度 O(n log n)。

程式範例：二分搜尋（JavaScript）

function binarySearch(arr, target) {
  let left = 0, right = arr.length - 1;
  while (left <= right) {
    const mid = Math.floor((left + right) / 2);
    if (arr[mid] === target) return mid;
    if (arr[mid] < target) left = mid + 1;
    else right = mid - 1;
  }
  return -1;
}
console.log(binarySearch([1, 3, 5, 7], 5)); // 2

陣列必須先排序；找不到時回傳 -1。

重點整理

  • 先確認輸入規模與資料特性。
  • 二分搜尋要求已排序資料。
  • 分治法將大問題拆成小問題再組合。
  • 時間複雜度用於比較演算法成長趨勢。
