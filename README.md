# CS Notes Hub

一個以 `AGENTS.md` 規範 AI 開發流程的資工課程筆記網站。

## 課程
- Java：物件導向、繼承、多型
- Algorithm：時間複雜度、排序
- Operating System：Process、Thread、Race Condition

## 技術
HTML、CSS、原生 JavaScript；無需建置，直接用 GitHub Pages 發布。

## 擴充方式
對 AI 說：「請先閱讀 AGENTS.md，按照規則新增 Python 筆記頁面，並更新首頁卡片。」AI 應遵守固定版型、命名、連結與驗收流程。

## 本機預覽
直接開啟 `index.html`。
